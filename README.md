# Study Room Reservation System for UTD

## Project Overview

This is a software engineering project for CE/CS/SE 3354 at UTD. Its purpose is to help students find available study rooms on campus and reserve them for individual or group study.

Students will be able to:
- Search for rooms by date, time, and capacity.
- View available time slots.
- Make reservations.
- Cancel existing bookings.

Authorized administrators will be able to manage study room listings.

## Project Scope

### In Scope

- Display study rooms, locations, and capacities.
- Search for available rooms by date and time.
- Filter rooms by minimum capacity.
- Make and cancel reservations.
- Prevent overlapping reservations.
- Allow authorized administrators to manage room listings.

### Out of Scope

- Physical door-lock or Comet Card integration.
- Real-time occupancy monitoring through sensors or cameras.
- UTD Duo authentication integration.
- Integration with existing university scheduling systems.
- Payment processing and SMS notifications.
